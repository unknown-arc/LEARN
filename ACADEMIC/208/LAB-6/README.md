# JavaScript Practice Lab

A beginner-friendly website for the 10 exercises in the supplied JavaScript Assignment Set.

## Project structure

- `index.html` — page content and form controls
- `css/style.css` — layout, colors, responsive styles
- `js/script.js` — JavaScript solutions and interactions

## Run locally

1. Extract the ZIP file.
2. Open `index.html` in a browser.
3. Enter values and click the buttons to run each exercise.

No framework, package installation, or backend is required.

## Included assignments

1. Even or Odd
2. Largest of Two Numbers
3. Simple Calculator (including division-by-zero handling)
4. Positive, Negative or Zero
5. Sum of First N Natural Numbers
6. Multiplication Table
7. Factorial (including 0!)
8. Count Digits
9. Reverse a Number
10. Prime Number Check (tests divisors up to the square root)

The assignment cards also include simple filters and a completion progress indicator.
