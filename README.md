# TROAL — Step 1: Basic Website Shell

A static website concept built with HTML, CSS, and vanilla JavaScript.

## Included
- Header with TROAL branding and navigation
- Intro/description area
- One Academic card as the main content card
- Short About TROAL description section
- Footer
- Responsive layout

## Run
Open `index.html` in a browser, or open the folder in VS Code and use Live Server.

The Academic card is intentionally not linked yet. Next, decide what should happen when it is opened.
