# TROAL — GitHub-powered learning directory

A static Neo-Brutalism site that discovers folders from a **public** GitHub repository using GitHub's Contents API.

## Setup

1. Put the site files in your GitHub Pages repository.
2. Edit `script.js`: set `GITHUB_OWNER`, `GITHUB_REPO`, `GITHUB_BRANCH`.
3. If the site files live in a repository subfolder, set `ROOT_PATH` to that folder.
4. Enable GitHub Pages in repository Settings.

## How it works

- Homepage links to `/ACADEMIC/` and `/LEARNING/`.
- Directory pages fetch contents from GitHub at runtime, so new committed folders appear without updating a manifest.
- Folder paths retain exact case: `/ACADEMIC/201/LAB-1/`.
- The included example folders have their own `index.html` files and load shared assets using relative paths.

## Important limitation

Browser JavaScript cannot create/commit an `index.html` to GitHub. A folder is discovered automatically, but if you need every newly created folder to have its own `index.html`, that file must be committed with the folder (or generated by a GitHub Actions workflow). For private repositories, do not place a token in frontend JavaScript; use a backend or build-time workflow instead.
